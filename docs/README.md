# py-CIPro documentation

py-CIPro interfaces with the pinned CIPro Wolfram Language release and
implements selected complete-intersection geometry operations in Python.

- [Install and choose a backend](installation.md) for local setup and verification.
- [API index](api.md) and [method concordance](concordance.md) map the Python
  and Wolfram entry points and their supported domains.
- [Dashboard](dashboard.md) explains the local archive explorer, method lab,
  and packaged manuscript.
- [Research data](research.md) explains the pinned CICY archive, record fields,
  and exact independent calculations.
- [Manuscript sources](manuscript/README.md) and [build guide](manuscript.md)
  reproduce the paper, figures and evidence records.
- [Wolfram runtime guide](wolfram-api.md) covers activated local sessions and
  the separate cloud interfaces.

Use the [repository citation](../CITATION.cff) when citing the software or
its archived manuscript.
