    Data and methods
    The catalogue shows stored CIPro records. Hodge pairs group records with equal h1,1 and h2,1, and a pair can occur in several configurations. For Calabi–Yau threefolds, χ = 2(h1,1 − h2,1). Product rows retain their archived Euler values, and the JSON export preserves their stored Hodge placeholders.
