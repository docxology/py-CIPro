# Abstract {.unnumbered}

Complete-intersection Calabi–Yau data can represent an ambient presentation, an integral lattice, or a variety defined by particular equations. These choices govern which geometric conclusions the data support. Using py-CIPro and independent integer calculations, we reproduce the Euler characteristics and {{CHERN_AMBIENT_PAIRINGS}} second Chern pairings of {{CICY3_RECORDS}} configurations in the pinned CIPro archive. A fixed ample polarization yields {{CHERN_MODAL_SIGNATURES}} distinct degree and Chern-pairing signatures at the modal Hodge pair. Divisibility of the cubic form and second Chern functional on the ambient divisor lattice distinguishes records within {{INTEGRAL_HODGE_SPLIT}} of {{INTEGRAL_HODGE_GROUPS}} non-product Hodge groups. For two rank-one complete intersections with the same Hodge numbers, the divisibilities differ on the full integral lattice.

Giving each non-product Hodge pair equal weight changes the median Euler characteristic from {{ATLAS_PRESENTATION_MEDIAN}} to {{ATLAS_PAIR_MEDIAN}}. An exact decomposition separates how each Hodge stratum contributes to the change in the released favorability flag's weighted share. On a specified smooth bicubic, rational multiplication-map ranks give all four cohomology dimensions at {{BICUBIC_EXACT_POINTS}} line-bundle charges. The dimensions differ from the generic benchmark at {{BICUBIC_EXACT_JUMPING_POINTS}} charges, with the same index throughout. The pinned inputs, Python calculations, source records, and figure generators allow each result to be reproduced.
