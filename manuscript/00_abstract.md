# Abstract

CIPro computes with complete intersections in products of projective spaces and
with line bundles on those varieties. py-CIPro exposes the upstream Wolfram
Language implementation to Python through a local Wolfram kernel. The interface
uses the package's exported names and preserves its association-based inputs,
property and modification keys, and symbolic outputs. This note describes the
execution boundary and the evidence required to reproduce a calculation from the
official CIPro 1.0 release.
